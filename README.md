# 囍事銀行電子喜帖

永軒與昀蓁的婚禮電子喜帖，以 LOVE BANK 終身聯名帳戶對帳單為設計主題。網頁提供婚宴資訊、Google 地圖、LINE 官方帳號、出席回覆文字產生器，以及列印／儲存 PDF 功能。

## 開啟

直接以瀏覽器開啟 `index.html`，或將此資料夾部署至靜態網站代管服務。專案不需要建置工具或伺服器端程式。

## 專案檔案

- `index.html`：喜帖內容與可存取的表單標記。
- `assets/css/style.css`：手機、桌機及 A4 列印樣式。
- `assets/js/main.js`：RSVP 回覆文字複製、行事曆下載與列印操作。
- `assets/images/couple-photo.jpg`：新人婚紗照。
- `v1_wedding_bank_statement_html_architecture.md`：版面架構與維護說明。

## 賓客回覆

表單會依賓客填寫的稱呼、出席狀況及人數組成文字，並嘗試複製到剪貼簿。賓客需將文字貼回收到喜帖的對話送出；本網站不會收集或儲存回覆。
